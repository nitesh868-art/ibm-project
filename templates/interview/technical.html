Core concepts tested in technical rounds across top tech companies

Data Structures & Algorithms
  • Arrays & Strings: Two-pointer approach, sliding window, prefix sums.
  • LinkedLists: Reverse linked list, detect cycles (Floyd's Algorithm).
  • Trees & Graphs: BST operations, BFS, DFS, Dijkstra's algorithm.
  • Dynamic Programming: 0/1 Knapsack, Longest Common Subsequence.
Database Management (DBMS)
  • SQL Queries: JOINs (Inner, Left, Right), GROUP BY, HAVING, Subqueries.
  • ACID Properties: Atomicity, Consistency, Isolation, Durability.
  • Normalization: 1NF, 2NF, 3NF, BCNF with functional dependencies.
  • Indexing: B-Trees, Hash indexes, Clustered vs Non-clustered.
Operating Systems (OS)
  • Process vs Thread: Context switching, IPC mechanisms.
  • Synchronization: Critical Section, Mutex, Semaphores, Deadlocks.
  • Memory Management: Paging, Segmentation, Virtual Memory, Page replacement.
Object-Oriented Programming (OOP)
  • 4 Pillars: Encapsulation, Abstraction, Inheritance, Polymorphism.
  • Overloading vs Overriding: Compile-time vs Run-time polymorphism.
  • Design Patterns: Singleton, Factory, Observer basics.
